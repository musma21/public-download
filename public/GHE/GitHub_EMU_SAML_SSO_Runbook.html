1. 개요 및 배경

본 런북은 신규 Microsoft Entra ID 테넌트와 Azure 구독을 기준으로 GitHub Enterprise Cloud의 Enterprise Managed Users(EMU) 환경을 처음부터 구축하고, SAML SSO 및 SCIM 자동 프로비저닝을 구성하는 전체 절차를 단계별로 정리한 문서입니다.

2026년 6월 1일부로 GitHub Copilot이 사용량 기반(Usage-based / AI Credit) 과금으로 전환됨에 따라, 기존의 ‘트라이얼 기반 평가’ 방식보다는 Production EMU Enterprise를 생성하고 Azure 구독을 직접 연결하는 방식을 권장합니다.

셋업 계정 암호 설정
작업자 · GitHub EMU Admin
작업 절차
  1. 메일은 위에서 열어 놓은 브라우저 창이 아니라 메일 앱 또는 별도 브라우저에서 확인

💡 Tip

이 셋업 계정 <shortcode>_admin은 Break-glass(비상용) 관리자 계정이라고도 불립니다. 초기 셋업에서만 주로 쓰이고, 실제 운영은 별도 Enterprise Owner로 진행합니다.

STEP3
SCIM Token (PAT) 생성
작업자 · GitHub EMU Admin
작업 절차
  1. 반드시 <shortcode>_admin (setup user)로 로그인한 상태에서 진행
  2. 경로: 우상단 프로필 → Enterprise → Settings → Identity provider → Generate SCIM token (보통 최초 로그인한 그 페이지)
  3. Scope: scim:enterprise 만 선택 (보통 자동으로 선택되어 있음)
  4. Expiration: No expiration (만료 없음)
  5. 하단 Generate token 클릭
  6. 생성된 토큰을 비밀번호 관리 도구 등 안전한 곳에 저장

STEP4
Azure 구독 연결 (과금)
작업자 · GitHub EMU Admin
작업 위치
Enterprise → Billing & Licensing → Payment information → “Metered billing via Azure” → Add Azure Subscription
작업 절차
  1. GitHub Enterprise 페이지 상단 Billing & Licensing 탭 클릭
  2. Payment information 이동 → Billing / Shipping 정보 입력 후 저장
  3. Payment method 이동 → Azure Subscription 클릭
  4. Azure(Entra) 로그인 → 테넌트 전역 관리자 동의(admin consent) 필요
  5. 연결할 Azure Subscription ID 선택 → Connect

⚠️ 주의

구독 선택에는 Azure Subscription Owner 권한이 필요합니다. 이후 GH Copilot / GH AS / GH Enterprise 과금이 Azure 구독으로 청구됩니다. 단, 현재 상태는 어떤 Organization도 추가되어 있지 않은 상태이므로 Activate 하여도 할당되는 좌석은 0입니다.

⏱️ Activation 이후 GitHub Enterprise 및 GitHub Advanced Security의 트라이얼은 종료됩니다.

  1. 다시 GitHub Enterprise 페이지 상단 Billing & Licensing 탭 클릭
  2. 왼편 Licensing 클릭 → “Copilot” 섹션으로 스크롤 다운
  3. Contact support to enable 버튼 클릭하여 (혹은 support.github.com) GH Copilot을 해당 엔터프라이즈 계정에 활성화되도록 요청
  4. Your account에서 작업 중인 Enterprise 계정과 “GitHub Enterprise Cloud”를 선택
  5. 제목은 Ask to enable GitHub Copilot on slug: <slug>, 본문도 동일하고, 이슈 타입은 Usage, 플랜은 구매할(혹은 이미 한) GH Copilot Plan 선택
  6. Copilot의 권고 무시하고, 하단의 Continue to create a ticket 클릭하여 케이스 오픈
  7. GitHub Support를 통해 GH Copilot이 활성화되면, 메일을 통해 확인할 수 있으며, Contact support to enable 녹색 버튼이 Enable Copilot으로 바뀝니다. 일단 아래 스텝을 진행하고, GH Copilot이 활성화되면 아래 STEP 13을 밟습니다.

    • (8월말까지 프로모션 기간이므로 $70 설정도 고려)
  2. 사용자별 예외 설정도 가능하나, 현재 단계에서는 진행하지 않음
  3. Enterprise Spending Limit 설정
    • Budget Type : AI credit budget
    • Budget Scope : Enterprise
    • Budget : 0
  4. Billing Information 입력 후 저장
  5. Payment method에 Azure subscription 추가
  6. Activate

💡 결제·활성화 참고

Payment Method를 Azure로 선택하면 Billing Tenant ID 선택 후 Azure 구독 ID가 표시됩니다. 확신이 없다면 M365 관리자 또는 Azure 구독 소유자에게 문의하십시오.
