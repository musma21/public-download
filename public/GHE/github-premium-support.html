GitHub Premium Support 와 Microsoft Unified Support 의 관계

Unified Support 계약과 GitHub Premium Support 가 어떻게 연결되는지, 그리고 반드시 짚어야 할 오해 포인트를 정리했습니다.

Microsoft Unified Support GitHub Premium Support 자격(Eligibility) vs 지원 범위

핵심 메시지

Unified Support 계약을 가진 고객은 GitHub Premium Support를 받을 수 있습니다.

위 화면처럼, Microsoft Unified Support 플랜을 보유하면 GitHub Premium Support 자격이 함께 열립니다.

🔗 자세히 보기 : https://github.com/enterprise/premium-support

여기서 꼭 주의할 점 🚨

두 문장은 완전히 다릅니다. 헷갈리면 기대치가 어긋납니다.

🚨 오해 (틀린 이해)

Unified Support 수준으로 GitHub 케이스를 지원한다.

✅ 정확한 이해

Unified Support가 있기에 GitHub Premium 을 받을 자격이 된다.

⚠️ 즉, 이런 뜻입니다

Unified Support에서 받는 CSAM의 케이스 지원 방식을 GitHub Premium 지원에서는 동일하게 기대할 수 없습니다.

그러면 무엇이 필요한가요?

  • GitHub 측의 더 높은 밀착 지원을 원한다면, GitHub 과 별도로 Premium Plus 계약을 체결해야 합니다.
  • Unified Support 자격만으로는 GitHub 쪽의 전담·케이스 밀착 관리까지 포함되지 않습니다.

결론

Unified Support 의 CSAM 은
GitHub Premium Support 를 지원할 의무가 없습니다.

Unified Support 는 GitHub Premium Support 를 받을 “자격”을 제공하는 것이며, GitHub 케이스에 대한 CSAM 급의 밀착 지원은 Premium Plus 별도 계약의 영역입니다.
